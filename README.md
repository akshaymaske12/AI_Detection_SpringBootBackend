# AI Detection Backend

Spring Boot backend for detecting AI-generated content. Connects to MySQL to store scan results, probability scores, and logs.

## Tech Stack
- Java 17+
- Spring Boot 3
- Spring Data JPA (Hibernate)
- MySQL
- Maven

## Prerequisites
- JDK 17 or higher
- MySQL Server
- Maven

## Database Setup
Create a new database in MySQL:

```sql
CREATE DATABASE ai_detection_db;
